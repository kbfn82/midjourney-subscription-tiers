## 订阅流程：从账户页到 Stripe 结账

步骤本身很短，容易出错的是结账页上的几个默认值。先登录账号，进入账户管理页（Manage Subscription），向下滚动到套餐区，在目标套餐下点 Subscribe，然后进入 Stripe 结账页面完成付款。付款成功后回到账户页，套餐会显示为已激活。

**年付是默认选中的。** 这是中文读者最容易踩的坑：结账页默认按年付展示，全年费用一次性扣。要按月付，必须在选套餐之前先点 “Monthly Billing” 标签切换，否则你以为在比较月价，实际下的是年单。年付确实便宜 20%，值不值得看你打不打算用满一年。

**账单邮箱在结账时定死。** 一旦在 Stripe 页面填好账单邮箱，之后要改必须联系账单客服；发票开出后不能修改。公司报销、工作室记账的，付款前把抬头和邮箱核对一遍再点确认。

**确认邮件发到账单邮箱，不是登录邮箱。** 发票和收据在同一封邮件里。用工作邮箱登录、用个人邮箱结账，收据就落在个人邮箱里，找起来很费劲。

结账走 Stripe。官方帮助页列出的是主流信用卡（Visa、Mastercard、American Express）以及部分地区可用的 Apple Pay、Google Pay、Amazon Pay、Link 等钱包，Alipay 也在其列；结账页显示哪些选项，就能用哪些，PayPal 不在支持范围内。

## 每档到底能生成多少图

Midjourney 卖的是 GPU 时间，不是图片张数，所以「能出多少张」要按官方给的耗时估算。一次 SD 四图提示词约消耗 0.8 GPU 分钟，HD 约 1.3 分钟。按 0.8 分钟折算，四档每月大致能跑：

- Basic：约 250 次 SD 提示词，约 1,000 张图
- Standard：约 1,125 次，约 4,500 张图
- Pro：约 2,250 次，约 9,000 张图
- Mega：约 4,500 次，约 18,000 张图

换算成单张成本，Standard 及以上约 $0.007 一张，一个四图提示词约 $0.027；Basic 因为单价高，约 $0.01 一张；用 $4/小时加购的时间约 $0.013 一张。这组数字是估算，实际消耗随模型版本、放大、重绘、视频而变，所有操作吃的是同一个 Fast 时间池子。

视频的消耗量级完全不同。一批四段 SD 视频约 8 GPU 分钟，一批四段 HD 视频约 26 分钟，差不多是一次图像提示词的十倍。放在 Standard 上，一批 SD 视频折合约 $0.27，HD 批次约 $0.87。Basic 的 200 分钟听着不少，按 8 分钟一批算，大约 25 个 SD 视频批次就见底，所以拿 Basic 做视频基本只够试手。

## Fast 时间用完之后会怎样

Basic 没有 Relax 模式，3.3 小时用完，生成直接停，只能等下一个计费周期，或者按 $4/小时加购。

Standard 及以上在 Fast 时间耗尽后可以切到 Relax 模式：低优先级排队，出图不消耗 Fast 时间。图片从 Standard 起无限 Relax，视频的 Relax 要 Pro 和 Mega。急着交稿时 Relax 的排队会让人难受，这也是很多人明明有 Relax 还去买加购时间的原因。

**Fast 小时不结转。** 这个月没用完的时间，续费时清零，年付也一样。指望买大套餐当缓冲、把余量留到下个月赶项目，行不通。选档时按峰值用量估，别按年度总量摊。

并发是另一个隐性限制。Basic 和 Standard 最多同时跑 3 个出图任务，Pro 和 Mega 是 12 个，第 4 个（或第 13 个）任务要排队，跟剩余额度多少无关。三个人同时提交，第四个人就会卡住，工作室撞的往往是这条线，不是小时数。

Turbo 模式按双倍 Fast 时间计费，适合赶一两个急活，不适合当日常设置。官方也说明过 V8.1 不支持 Turbo。

至于「加购还是升级」，第三方测算给过两个参考点：每月用超过约 8.3 Fast 小时，Standard 就比「Basic 加加购时间」便宜；每月超过约 45 Fast 小时，Mega 才开始比「Pro 加加购」划算。低于这两条线，加购更省。

## 这两类人不必订 Midjourney

**只想要免费起步的。** Krea 免费计划每天 100 单位、含 Krea 3；Google 的 Nano Banana 2 在 Google 应用限额内可免费使用；FLUX.2 开放权重，可以本地跑；ChatGPT 免费档每天能出少量图。这些足够验证「AI 出图这件事对我有没有用」，验证完再决定要不要付费。

## 常见问题

**有免费试用吗？** 官网和 Discord 都没有，只有 niji journey 手机 App 内有有限试用。

**年付能改成月付吗？** 年付是一次性付全年，中途没有切换成月付的入口；想按月付，要在结账前点 “Monthly Billing” 标签，或者到期后取消重订。

**订阅后图片是公开的吗？** Basic 和 Standard 默认进公共画廊，Pro 和 Mega 可以用 Stealth 隐藏，但公开 Discord 频道里发的内容不受保护。

**V8.2 是什么？** 当前默认模型，2026 年 7 月 24 日起成为默认版本，主打更强的美学表现和个性化；HD 原生 2,048 像素，不需要单独放大。

**取消后还能用吗？** 能，用到已付周期结束，已生成的作品所有权不变。
